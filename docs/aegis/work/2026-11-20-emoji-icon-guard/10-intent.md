# 九键笑脸键原生图标写入守卫

- 用户目标：修掉九键拼音／符号页切换时，换行键上短暂出现的原生笑脸（带圆圈）图标闪烁。
- 现象与根因：动作键把表情键的前景图搬走后，原生 `-[GKBSoftKeyView updateView]` 每一轮布局都会把笑脸重新写回 `GKBImageViewWithBackground` 的前景图层；我们的清除发生在下一拍轮询／布局，两者之间那一帧就是用户看到的圆圈。
- 方案（A：源头拦截）：swizzle `-[GKBSoftKeyView updateView]`，在原实现写完的同一轮立刻清掉已绑定键的前景，帧提交前图层已经是空的。
- 边界：只处理当前已绑定的那一个表情键；不改 alpha/hidden/背景层/键帽样式；不碰其它键；不拦截任何触摸事件；不新增原生几何或键盘高度改动。
- 成功证据：源码契约测试、全量回归、CI arm64 编译、注入包结构校验；真机上的闪烁是否消失仍需用户验收。
